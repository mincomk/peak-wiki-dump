## Message from Landcrab

**Heya scouts! Here's the biweekly patch adding more [maps](https://peak.wiki.gg/wiki/Maps) into rotation (that's why the patch is so big, they're full of maps, so stop asking). We also tightened up the lobby security and fixed the invisible player issue etc!** ![salute](../../images/Steam_Emoticon_-_PEAKsalute.png)

As we mentioned in our [holiday post](1.50.a.md), it will take a while between bigger updates. The next one we're working on right now focuses on some requested features, but there won't be another [biome](https://peak.wiki.gg/wiki/Biome) until later this year ![bingbong](../../images/Steam_Emoticon_-_PEAKbingbong.png)

Enjoy!

## Patch Notes

**Added:**

- More generated [maps](https://peak.wiki.gg/wiki/Maps) for the map rotation

**Fixes:**

- Fixed some broken idle animations
- Tightened up lobby security so players who shouldn't be in there get kicked faster
- Fixed some cases where the [scout report](https://peak.wiki.gg/wiki/Scout_report) does Weird Stuff
- Fixed the issue where the lobby host would sometimes be invisible to players with slow computers

**Modder Notes**

- PEAK has been updated to build off of Unity 6.0.62f1
