The **Bandages** is a [consumable](https://peak.wiki.gg/wiki/Consumable) item in *[PEAK](Peak%20%28game%29.md)*. It can be found in [luggages](Luggage.md).

Using bandages removes [![Injury](../../images/Status_Injury.png)](Stamina%20bar.md#Injury) **30** [Injury](Stamina%20bar.md#Injury). Cooking them has no effect, even if incinerated. Use time is 4 seconds.
