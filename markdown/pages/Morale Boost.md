# Morale Boost

**Morale Boost** is a mechanic in *[PEAK](Peak%20%28game%29.md)* which occurs upon lighting a [Campfire](Campfire.md) or using the [![](../../images/Scoutmaster%27s_Bugle.png)](Scoutmaster%27s%20Bugle.md) [Scoutmaster's Bugle](Scoutmaster%27s%20Bugle.md).

When a Morale Boost is activated, the text "Morale Boost!" will briefly appear above the [Stamina bar](Stamina%20bar.md) and grant [![Bonus stamina](../../images/Status_Bonus_stamina.png)](Stamina%20bar.md#Bonus_stamina) **25** [Bonus stamina](Stamina%20bar.md#Bonus_stamina) to each alive Scout if triggered by a [Campfire](Campfire.md) or [![Bonus stamina](../../images/Status_Bonus_stamina.png)](Stamina%20bar.md#Bonus_stamina) **100** [Bonus stamina](Stamina%20bar.md#Bonus_stamina) to each alive player (regardless of distance) if triggered the [![](../../images/Scoutmaster%27s_Bugle.png)](Scoutmaster%27s%20Bugle.md) [Scoutmaster's Bugle](Scoutmaster%27s%20Bugle.md).
