# 食物

![](https://commons.wiki.gg/images/Cleanup.svg?ee4d39)

This page does not meet **PEAK Wiki**'s page quality standards. You can edit it to help fix grammar, formatting, or code issues.

吃掉*[PEAK](Peak%20%28game%29.md)*中的**食物**可以降低[![飢餓度](../../images/Status_%E9%A3%A2%E9%A4%93%E5%BA%A6.png)](%E8%83%BD%E9%87%8F%E6%A2%9D.md#飢餓度) [飢餓度](%E8%83%BD%E9%87%8F%E6%A2%9D.md#飢餓度)或提升[![額外能量](../../images/Status_%E9%A1%8D%E5%A4%96%E8%83%BD%E9%87%8F.png)](%E8%83%BD%E9%87%8F%E6%A2%9D.md#額外能量) [額外能量](%E8%83%BD%E9%87%8F%E6%A2%9D.md#額外能量)。某些食物會造成含有Template:毒性，也有些會提供額外效果，例如治療[![受傷](../../images/Status_%E5%8F%97%E5%82%B7.png)](%E8%83%BD%E9%87%8F%E6%A2%9D.md#受傷) [受傷](%E8%83%BD%E9%87%8F%E6%A2%9D.md#受傷)或移除[![燒傷](../../images/Status_%E7%87%92%E5%82%B7.png)](%E8%83%BD%E9%87%8F%E6%A2%9D.md#燒傷) [燒傷](%E8%83%BD%E9%87%8F%E6%A2%9D.md#燒傷)。

玩家可以找到各種天然食物，像是水果、蘑菇，也能在行李箱中找到包裝食物。

[煮熟](%E7%83%B9%E9%A3%AA.md)的食物可以降低兩倍的飢餓度且獲得更多額外能量。

下方表格列出所有遊戲中可獲得的食物，以及他們的效果和重量。

## 天然食物

在幾乎各種生態系中都能發現天然食物。你可以在一場遊戲中只進食過天然食物來獲得成就：Template:徽章，使用某些特殊道具（例如[萬能藥](https://peak.wiki.gg/wiki/Special%3AUpload%3FwpDestFile%3D%E8%90%AC%E8%83%BD%E8%97%A5.png) 萬能藥和[潘朵拉的午餐盒子](https://peak.wiki.gg/wiki/Special%3AUpload%3FwpDestFile%3D%E6%BD%98%E6%9C%B5%E6%8B%89%E7%9A%84%E5%8D%88%E9%A4%90%E7%9B%92%E5%AD%90.png) 潘朵拉的午餐盒子）不會影響到這個成就。
