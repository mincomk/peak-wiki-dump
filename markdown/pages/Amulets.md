# Amulets

**Amulets** are four special [Mystical items](https://peak.wiki.gg/wiki/Mystical_items) which can be found at [Amulet Statues](https://peak.wiki.gg/wiki/Amulet_Statues). One can be found in each of the first four biomes of the island (i.e. [Shore](Shore.md), [Tropics](Tropics.md)/[Roots](Roots.md), [Alpine](Alpine.md)/[Mesa](Mesa.md), and [Caldera](Caldera.md)/[Gloom](Gloom.md)). Each of them provides a beneficial effect at the cost of inflicting [![Petrify](../../images/Status_Petrify.png)](Stamina%20bar.md#Petrify) [Petrify](Stamina%20bar.md#Petrify) upon the user. Amulets do not have a usage limit.

## List

### Scout's Ambition.png Scout's Ambition

Main article: [Scout's Ambition](Scout%27s%20Ambition.md)

Generates an aura with a radius of **9.6 meters** around the user for **8 seconds**. Scouts within the aura gain [![Infinite Stamina](../../images/Status_Infinite_Stamina.png)](Stamina%20bar.md#Infinite_Stamina) [Infinite Stamina](Stamina%20bar.md#Infinite_Stamina) while within the radius for the duration of the effect. The user is inflicted [![Petrify](../../images/Status_Petrify.png)](Stamina%20bar.md#Petrify) **30** [Petrify](Stamina%20bar.md#Petrify) per activation.

### Scout's Generosity.png Scout's Generosity

Main article: [Scout's Generosity](Scout%27s%20Generosity.md)

Duplicates a targeted item, inflicting [![Petrify](../../images/Status_Petrify.png)](Stamina%20bar.md#Petrify) [Petrify](Stamina%20bar.md#Petrify) based on the type of item; [![Petrify](../../images/Status_Petrify.png)](Stamina%20bar.md#Petrify) **25** for a regular item and [![Petrify](../../images/Status_Petrify.png)](Stamina%20bar.md#Petrify) **45** for a mystical item.

### Scout's Initiative.png Scout's Initiative

Main article: [Scout's Initiative](Scout%27s%20Initiative.md)

Lifts Scouts within **12.8 meters** of the user (including the user) into the air, then gives them [wind walking](Wind%20walking.md) for **3 seconds**. Inflicts [![Petrify](../../images/Status_Petrify.png)](Stamina%20bar.md#Petrify) **7** [Petrify](Stamina%20bar.md#Petrify) per use.

### Scout's Tenacity.png Scout's Tenacity

Main article: [Scout's Tenacity](Scout%27s%20Tenacity.md)

Heals up to a total of **60** of [![Injury](../../images/Status_Injury.png)](Stamina%20bar.md#Injury) [Injury](Stamina%20bar.md#Injury), [![Spores](../../images/Status_Spores.png)](Stamina%20bar.md#Spores) [Spores](Stamina%20bar.md#Spores), [![Poison](../../images/Status_Poison.png)](Stamina%20bar.md#Poison) [Poison](Stamina%20bar.md#Poison), [![Cold](../../images/Status_Cold.png)](Stamina%20bar.md#Cold) [Cold](Stamina%20bar.md#Cold), [![Heat](../../images/Status_Heat.png)](Stamina%20bar.md#Heat) [Heat](Stamina%20bar.md#Heat), and [![Drowsy](../../images/Status_Drowsy.png)](Stamina%20bar.md#Drowsy) [Drowsy](Stamina%20bar.md#Drowsy), then applies [![Invincibility](../../images/Status_Invincibility.png)](Stamina%20bar.md#Invincibility) [Invincibility](Stamina%20bar.md#Invincibility) for **10 seconds**. Afterwards inflicts **10-30** [![Petrify](../../images/Status_Petrify.png)](Stamina%20bar.md#Petrify) [Petrify](Stamina%20bar.md#Petrify), based on the amount healed. Can be used on oneself or another Scout.
