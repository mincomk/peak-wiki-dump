The **Scout Effigy** is a [consumable](https://peak.wiki.gg/wiki/Consumable) [mystical item](https://peak.wiki.gg/wiki/Mystical_item) in *[PEAK](Peak%20%28game%29.md)* that can be obtained from Ancient Luggage or the [Ancient Statues](https://peak.wiki.gg/wiki/Ancient_Statues). The effigy can be used to resurrect a random dead or unconscious player at the target location.

If the effigy is placed while there are no ghost scouts, the effigy is still consumed without resurrecting any player.

[Cooking](Cooking.md) a Scout Effigy causes it to grant [![Bonus stamina](../../images/Status_Bonus_stamina.png)](Stamina%20bar.md#Bonus_stamina) **10** [Bonus stamina](Stamina%20bar.md#Bonus_stamina) when used. Incinerating gives the user [![Poison](../../images/Status_Poison.png)](Stamina%20bar.md#Poison) [Poison](Stamina%20bar.md#Poison), as usual for food.

The **Scout Effigy** will not spawn when playing alone.

## Trivia

- The Scout Effigy is visually a smaller version of the [Ancient Statues](https://peak.wiki.gg/wiki/Ancient_Statues).
- This is the one of the only items in the game that is able to [resurrect Scouts](Scout.md#Resurrection) while not giving them any [![Curse](../../images/Status_Curse.png)](Stamina%20bar.md#Curse) [Curse](Stamina%20bar.md#Curse), the other being [![](../../images/Checkpoint_Flag.png)](Checkpoint%20Flag.md) [Checkpoint Flag](Checkpoint%20Flag.md).
